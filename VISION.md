This is an art project attempting to create generative animations that culminate in a static image, based on real tree morphologies, applying Goethe's observations in Metamorphosis of Plants (e.g. exapnsion / contraction pahses with onomastatic fusion at extreme contraction ranges).

It is also a technical toy / puzzle. I want to use abstract algebra to express composable, generative animation structures. A semiring, specifically, using addition for expressing animations in parallel and multiplication for sequential ones. At the same time, it will have lots of design and aesthetic decisions. I'm interested in exercising at this intersection of modalities. This should entail lots of interesting assertions via static analysis, formal verification via Bend 2, invariants and evals, all whilst working in a jig. But let's see!

*A note for posterity:* this vision worked really well as the seed of an idea, but intentionally challenging it yielded much better operating models. RFC_001 covers the specifics. At a general level, it's worth noting that a half-formed idea functioned well as inspiration but loose attachment to it _in the right places_ enabled much better outcomes.
