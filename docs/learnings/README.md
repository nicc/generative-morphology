# Learnings

Dated write-ups of spikes and experiments: things we tried in order to find out, as opposed to things we decided. One file per spike, `YYYY-MM-DD-short-slug.md`.

Each covers:

- **Question.** What we wanted to find out.
- **What we tried.** Including the seeds and parameters, so the result can be reproduced (principle 3).
- **What we saw.** Observations first, kept separate from interpretation. Screenshots alongside the file where they help.
- **What it changes.** The RFC, spec, principle or issue this feeds, or "nothing" and why.

These are a record, not a source of rules. If a learning should constrain the work, it goes through an RFC.
